Pengaturan Database Google Sheets

Sistem ini menyimpan data secara permanen di spreadsheet Google Drive pribadi Anda via Google Apps Script Web App. Semua kerabat yang membuka website ini akan melihat data yang sama (isi DEFAULT_GAS_URL di kode agar otomatis di semua perangkat).

Dapatkan URL ini saat melakukan Deploy as Web App di Google Apps Script.



      

      

        

           Petunjuk Singkat:
        

        
1. Buat Google Sheet baru di Drive Anda.

        
2. Buka menu Ekstensi → Apps Script dan tempel kode script backend.

        
3. Klik Deploy → New deployment → Web app.

        
4. Pilih akses: Who has access: Anyone (Siapa saja).

        
5. Salin URL Web App dan tempelkan di kotak di atas.
